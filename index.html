Konfidenzintervalle

Ein Konfidenzintervall gibt einen Bereich plausibler Werte für einen unbekannten Parameter an – hier den Mittelwert μ einer Population. Das Konfidenzniveau beschreibt, wie oft das Verfahren bei wiederholten Stichproben ein Intervall liefert, das μ tatsächlich enthält.

Wähle eine Verteilung, den Stichprobenumfang n und das Konfidenzniveau. Starte dann die Simulation: Für jede Stichprobe wird ein t-Intervall berechnet.
