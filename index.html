Konfidenzintervalle

Ein Konfidenzintervall gibt einen Bereich plausibler Werte für einen unbekannten Parameter an – hier den Mittelwert μ einer Population. Das Konfidenzniveau beschreibt, wie oft das Verfahren bei wiederholten Stichproben ein Intervall liefert, das μ tatsächlich enthält.

Wähle eine Verteilung, den Stichprobenumfang n und das Konfidenzniveau. Starte dann die Simulation: Für jede Stichprobe wird ein t-Intervall berechnet.

Von der Grundgesamtheit zur Stichprobe

Eine Studie möchte wissen, wie wichtig es Fachkräfte der Sozialen Arbeit finden, dass sich die Soziale Arbeit in politische Prozesse einbringt, zum Beispiel mit Abstimmungsempfehlungen. Dafür wird der Link zu einer Onlinebefragung an die Mitglieder von AvenirSocial verschickt. Die Studie kommt zum Schluss, dass sich die Soziale Arbeit deutlich stärker in politische Prozesse einmischen soll.
